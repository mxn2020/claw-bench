# Claw Bench

> 🧪 Agent benchmarking platform for comparing LLM performance.

[![CI](https://github.com/mxn2020/claw-bench/actions/workflows/ci.yml/badge.svg)](https://github.com/mxn2020/claw-bench/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Compare AI models across accuracy, latency, cost, and reliability for agent tasks.

## ✨ Features

- **🏆 Leaderboard** — Rank 8+ LLMs by overall score with trend indicators
- **🧪 Benchmarks** — 8 test suites (code gen, tool use, reasoning, latency, cost, etc.)
- **📊 Run History** — Track all benchmark executions with scores and costs
- **▶️ New Runs** — Configure and launch benchmark evaluations
- **🌗 Dark & Light Mode** — Clean scientific theme with IBM Plex fonts

## 🚀 Quick Start

```bash
git clone https://github.com/mxn2020/claw-bench.git
cd claw-bench && npm install && npm run dev
```

## 🧪 Testing

```bash
npx vitest run
```
